# Any3D-VLA: Enhancing VLA Robustness via Diverse Point Clouds

## Topic
3D-aware VLA via point-cloud fusion

## Background
Existing Vision-Language-Action (VLA) models typically consume only 2D images, so their spatial understanding is inherited from 2D backbones and stays brittle under small objects, viewpoint changes, and occlusions. The authors run a pilot study comparing different observation spaces and visual representations, and find that explicitly lifting visual input into point clouds yields 3D representations that complement the corresponding 2D representations better than implicit / reconstruction-based spatial priors (e.g., VGGT or depth-pretrained encoders). The paper aims to provide a plug-in 3D-injection pipeline for existing VLA backbones while tackling 3D-data scarcity and the cross-environment domain gap.

## Limitations & Research Problem
- **Limitation:** Implicit / reconstruction-based spatial priors (VGGT, depth-pretrained encoders) rely on reconstruction objectives, lack precise metric alignment, are imprecise for fine-grained spatial relationships, and are prone to spatial hallucination. Conversely, feeding depth as an extra image channel (image-plane RGBD) treats it as a 2D input and compromises the intrinsic topological structure of 3D data, so 2D backbones struggle to infer occlusion relationships and absolute scale from flattened depth maps.
- **Limitation:** 3D VLAs face a triple bottleneck — (1) 3D data is extremely scarce versus the massive amount of 2D image data; (2) 3D data from different sources (simulator / sensor / model-estimated) differs substantially in noise characteristics, scale distributions, and geometric biases (domain gap); (3) high-quality depth inputs are often required (expensive depth hardware).
- **Problem:** How can 3D information be injected into VLAs to strengthen spatial understanding while remaining robust to diverse, noisy, scale-biased point clouds and removing the deployment-time reliance on expensive depth sensors?

## Contributions
- Propose **Any3D-VLA**: by lifting visual input into point clouds, compressing them, and fusing 2D–3D representations, it offers a general, modular, plug-in framework for injecting 3D representations into existing VLA backbones.
- To address the scaling bottleneck of 3D VLA training and the cross-environment domain gap, introduce a **hybrid point-cloud training** strategy and construct a large-scale RGBD dataset for VLA tasks (Objaverse LVIS subset, 290 categories, 10,680 instances; simulator-synthesized plus several depth-estimation models).
- Extensive sim and real-world experiments. Real-world zero-shot average success rate reaches up to 62.5%, beating the strongest baseline SpatialVLA (33.3%) by **29.2 points**; after post-training it reaches up to **93.3%**. It stays robust even when depth is noisy or scale-biased, with additional generalization validated on LIBERO/CALVIN.

## Methodology
- **Overall architecture:** A VLM (InternLM2 1.8B) plus a conditional flow-matching action expert, connected via Progressive Action Generation (PAG); it follows GraspVLA's imitation-learning + PAG paradigm and outputs continuous end-effector action chunks.
- **How depth/3D enters the model (the core lifting chain):**
  1. **Lifting + 3D compression:** Using camera intrinsics (fx, fy, cx, cy), every valid depth pixel (u,v,d) is back-projected into a 3D point in the camera frame: x=(u−cx)d/fx, y=(v−cy)d/fy, z=d. To avoid feeding all points into the encoder, Sonata-style grid/voxel sampling is applied in (x,y,z) space (voxel size 1 cm): each non-empty voxel keeps one representative point inheriting color/normal — reducing ~30k–60k points to ~3k–8k points, giving a compact, spatially uniform 3D representation ("3D compression").
  2. **Dual encoders:** The compressed cloud is fed to a pretrained point-cloud encoder **Concerto** (joint 2D–3D self-supervised pretraining), taking point coordinates plus per-point attributes (color, normal) and producing per-point features f_i^3D (most parameters frozen, only the last few sparse-conv layers fine-tuned). In parallel a 2D image encoder (DINOv2 + SigLIP, dim 1024+1152=2176) produces patch-level tokens.
  3. **Patch-wise alignment:** Each 3D point is projected back to the image plane (u_i,v_i)=π(x_i), discretized over the ViT patch grid to obtain a patch index a_i; points falling into the same patch j are scatter-mean aggregated into a patch-level 3D feature g_j^3D, with a learnable empty token e^3D used when a patch contains no point. The key is doing native 3D understanding in the camera frame and then projecting back onto 2D patches, rather than encoding depth directly on the image plane.
- **2D–3D fusion mechanism:** A linear layer projects g_j^3D to the token dimension, h_j^3D=W_3D·g_j^3D; it is concatenated with the corresponding 2D token h_j^2D and passed through a small MLP to produce a residual δ_j=MLP([h_j^2D; h_j^3D]); a **gated residual fusion** then gives h_j^fused = h_j^2D + σ(g)·LayerNorm(δ_j), where g is a learnable scalar gate initialized to −2.1972 so σ(g) is small early in training. By design, 3D representations act as *corrections* to 2D representations rather than replacements, protecting the pretrained 2D features. The fused tokens, language tokens, and proprioceptive tokens are fed to the VLA backbone.
- **Training:** Joint training on the GRIT grounding dataset and the synthetic RGBD dataset; the VLM autoregressively predicts discrete bbox/grasp-pose tokens while the flow-matching action expert generates continuous actions. No explicit reconstruction loss is applied to depth/point clouds — gains flow only through the fused features h_fused, ensuring improvements stem from better spatial observation and representation.
- **Hybrid point-cloud training:** Setting 1 uses only simulator ground-truth clouds; Setting 2 trains from scratch on mixed sources (per trajectory, with fixed probability, pick the simulator/sensor cloud or a metric cloud estimated from a single RGB frame; mixing ratio Simulator/Sensor 30% / UniDepthV2 30% / Depth Anything 3 20% / MapAnything 20%); Setting 3 uses only sensor clouds. Setting 2 exposes the model to all cloud types, teaching geometric patterns invariant to the depth source and thus tolerating scale bias and the imperfections of model-estimated clouds.
- **Quantitative gains vs pure-RGB VLA:** In the pilot study (Table 2, simulation) point cloud–2D patch fusion is best, Single-Trial SR 61.1 vs 2D-only 45.3 (+15.8) and vs the second-best image-plane RGBD 56.8 (+4.3); the ablation (Table 6) goes from 2D-only 45.3 / 3D-only 44.2 to full 2D–3D fusion 61.1, showing that the right fusion of 2D semantics with 3D geometry is what matters. Real-world post-training (Table 3) Setting 2 + DA3: Task 1 93.3% / Task 2 86.7%, far above π0.5, GraspVLA, and SpatialVLA. On LIBERO it beats GraspVLA by 13.9%; adding the 3D branch into π0.5 raises LIBERO average 82.9→87.1 (DA3)/87.3 (Sim) and CALVIN average length 3.22→3.41/3.43. After 3D compression, inference runs at RealSense 2.0 FPS / DA3 1.7 FPS (2D baseline 3.0 FPS), an acceptable overhead.
