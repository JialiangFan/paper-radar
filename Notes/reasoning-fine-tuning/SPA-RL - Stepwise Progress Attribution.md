# SPA-RL: Reinforcing LLM Agents via Stepwise Progress Attribution

- **Authors**: 2025
- **Year/Venue**: 2025
- **ArXiv**: [2505.20732](https://arxiv.org/abs/2505.20732)
- **Tags**: #step-level-rl #progress-attribution #agent-training

## Problem
Agent RL 训练中，如何度量每一步对任务完成的"进度贡献"？

## Method
**Stepwise Progress Attribution**:
- 定义 progress metric：每步执行后，任务离完成有多近
- 将 credit 按 progress 贡献分配给每个 step

## Key Results
- Agent benchmarks 上提升显著
