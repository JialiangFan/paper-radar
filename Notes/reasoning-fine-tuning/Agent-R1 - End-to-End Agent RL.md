# Agent-R1: Training Powerful LLM Agents with End-to-End Reinforcement Learning

- **Authors**: 2025
- **Year/Venue**: 2025
- **ArXiv**: [2511.14460](https://arxiv.org/abs/2511.14460)
- **Tags**: #agent-rl #end-to-end #reasoning #hierarchical-reward

## Problem
LLM agent 训练缺乏统一的端到端 RL 框架。

## Method
- 统一框架同时优化 reasoning 和 action
- 使用 GRPO variants
- Hierarchical/stepwise reward propagation

## Key Results
- 多领域 agent benchmarks 上表现优异
- 端到端训练优于分阶段训练
