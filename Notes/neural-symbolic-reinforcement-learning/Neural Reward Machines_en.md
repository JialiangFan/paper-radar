# Neural Reward Machines

## Topic
Neurosymbolic Reward Automata

## Background
Non-Markovian reinforcement learning tasks require agents to reason over the entire history of state-action pairs, rendering standard MDP formulations inadequate. Reward Machines (RMs) address this by compiling temporal task specifications into automata that expose compositional reward structure, but they presuppose a known symbol grounding (SG) function mapping raw environment states to propositional symbols. In non-symbolic domains with continuous or high-dimensional observations (e.g., images), the SG function is typically unavailable and expensive to learn, severely limiting the applicability of RM-based methods.

## Limitations and Research Questions
- **Limitation 1:** Conventional Reward Machines require a fully known SG function---a precise mapping from raw states to Boolean symbols---which is infeasible in non-symbolic environments with continuous state spaces or image observations.
- **Limitation 2:** Pure deep RL approaches (e.g., RNN+A2C) can process raw inputs but cannot exploit temporal logic prior knowledge to accelerate learning, performing poorly on complex temporally extended tasks.
- **Limitation 3:** Existing work on semi-supervised symbol grounding (SSSG) lacks a systematic analysis of reasoning shortcuts---cases where multiple SG solutions are equally consistent with the data yet only one is semantically correct.
- **Problem:** How can temporal logic task knowledge be leveraged for non-Markovian RL when the SG function is completely unknown? How can unremovable reasoning shortcuts in a temporal specification be systematically identified?

## Contributions
- Introduces Neural Reward Machines (NRMs), a neurosymbolic framework based on Probabilistic Moore Machines that unifies logical reasoning and neural perception in a single differentiable model, supporting pure reasoning, pure learning, and joint reasoning-learning configurations.
- Combines NRMs with semi-supervised symbol grounding and RL: learns the SG function from environment reward feedback alone, given only the symbolic task knowledge (automaton structure), with no prior access to the grounding.
- Defines Unremovable Reasoning Shortcuts (URS) and proposes an efficient discovery algorithm (Algorithm 1) that identifies all structurally inherent reasoning shortcuts from the temporal specification alone, achieving approximately 10^3x speedup over brute-force search.
- Provides the first method that exploits temporal logic knowledge in single-task RL under a completely unknown SG function, with experiments demonstrating that NRM performance approaches the upper bound set by RMs with full prior knowledge.

## Methodology
- **Formal Definition:** An NRM is defined as a tuple (S, P, Q, R, q0, delta_tp, delta_rp, sg), where sg is a symbol grounding probability function mapping environment states to probability vectors over propositions, and delta_tp, delta_rp are probabilistic transition and reward functions. The formalism generalizes Probabilistic Moore Machines to accept non-symbolic inputs.
- **Neural Implementation:** Discrete Moore Machine operations are relaxed into continuous matrix multiplications. A temperature-controlled softmax (softmax_tau) approximates discrete outputs; as temperature decreases, the transition matrix M_t and reward matrix M_r converge toward one-hot encodings, enabling differentiable logical induction via backpropagation. The SG function is implemented as an arbitrary neural network (MLP for map states, CNN for image observations).
- **Three Operating Modes:** (1) Pure Reasoning---all NRM parameters are known; the machine produces reward signals for augmented-state RL without any data-driven training. (2) Pure Learning---all parameters are unknown; the entire automaton is learned from reward data via cross-entropy loss minimization. (3) Learning and Reasoning Integration---partial knowledge (e.g., M_t, M_r from the task specification) is combined with data-driven learning of unknown components (e.g., sg); this paper focuses on learning symbol grounding under this configuration.
- **RL Integration:** The framework uses A2C with the NRM-estimated automaton state concatenated to the environment state as augmented input to the policy network. The symbol grounder is trained on (state-sequence, reward-sequence) pairs collected through RL exploration, using potential-based reward shaping to provide incremental feedback. Grounder updates occur every 120 episodes for up to 100 epochs, interleaved with policy training.
- **Groundability Analysis and URS Algorithm:** Reasoning shortcuts are formally defined as non-identity symbol renamings that preserve formula output consistency. Algorithm 1 iteratively verifies candidate mappings over a finite but complete symbolic support, exploiting absorbing-state and working-map properties for pruning, efficiently enumerating all URS for a given temporal specification.
- **Experimental Setup:** Evaluated on Minecraft-inspired grid worlds with two observation modalities: a map environment (2D coordinates) and an image environment (64x64x3 pixel observations). Tasks are specified via LTL formulas covering Visit, Sequenced Visit, and Global Avoidance patterns across two difficulty classes. Baselines include RNN+A2C (no prior knowledge) and RM+A2C (full prior knowledge upper bound).
- **Key Results:** NRM+A2C performance consistently falls between RNN+A2C and RM+A2C, nearly matching the RM upper bound in the map environment. NRMs significantly outperform the RNN baseline across all tasks, with the advantage most pronounced on complex temporal tasks (Class 2). The URS discovery algorithm achieves approximately 1000x speedup over brute-force on all tested formulas.
