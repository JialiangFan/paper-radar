# DreamGuard: Efficient Runtime Guardrail for LLM Agents via Risk-Aware World Model

> arXiv: 2608.05695 | Year: 2026

## Topic
Risk-aware world model runtime guardrail

## Background
LLM agents now autonomously invoke external tools and act on external state, user data, and downstream services, so unsafe actions can cause irreversible consequences. Runtime guardrails — which inspect each proposed action in its trajectory context and intervene *before* execution — have become a key defense. However, most deployed guardrails are reactive: they judge the apparent safety of the current proposed action without modeling how risk evolves along the trajectory. This creates a blind spot for long-horizon risk, where individually benign steps (locate an internal file → move it to a workspace folder → create a public sharing link) accumulate into confidential data exposure.

## Limitations & Research Problem
- **Limitation:** (i) *Efficiency* — proactive guardrails typically feed whole trajectory histories to an LLM, are bounded by context length, require expensive autoregressive inference, and often incur multi-second per-step latency. (ii) *Prediction does not preserve risk evidence* — predicting future states and then judging them with a separate safety rule/judge means the prediction was never trained for risk discrimination, so the predicted latent state may lack the evidence needed to expose hazardous transitions. (iii) *Multi-horizon risk is hard to calibrate* — long-horizon evidence is weak before a hazard becomes explicit, while immediate-hazard evidence demands decisive intervention exactly at the current action boundary; the two complementary signals must be fused into a rule that warns early without excessive false alarms.
- **Problem:** How to build a lightweight, pre-action guardrail whose latent dynamics explicitly preserve evidence of hazardous transitions, and whose immediate-hazard and prefix-risk signals are calibrated into a PASS / HOLD / BLOCK decision?

## Contributions
- DreamGuard, an efficient runtime guardrail built on a lightweight risk-aware world model that maintains a compact recurrent latent state and estimates multi-horizon risk before action execution, enabling proactive intervention against both immediate hazards and long-horizon risks during real-time agent execution.
- Extensive evaluation on four agent safety benchmarks, outperforming generic, reactive, and proactive guardrail baselines in mitigating multi-horizon risk, intervening earlier on long-horizon risk, and end-to-end latency.
- An additional online guardrail evaluation with a live tool-calling agent, achieving the best safety–utility trade-off among evaluated guardrails.

## Methodology
- **Problem formulation:** at each step *t* the guardrail G receives x = (e, H_t, a_t) — task instruction, interleaved observation–action prefix, and the proposed action — and emits d ∈ {PASS, HOLD, BLOCK}. The objective is to fire HOLD/BLOCK strictly before the first hazard step t^haz while minimizing false alerts on safe trajectories.
- **Risk-aware world model:** an RSSM with six components — sequence model (GRU with LayerNorm, h_t = f(h_{t-1}, z_{t-1}, a_{t-1})), representation model (posterior z_t ~ q(z_t|h_t,o_t)), dynamics predictor (prior ẑ_t ~ p(ẑ_t|h_t)), observation predictor, immediate-hazard predictor, and prefix-risk predictor. The two risk heads score the **predicted successor prior state** ŝ_{t+1} = (h_{t+1}, ẑ_{t+1}), so risk is assessed before execution. The stochastic state is factorized categorical, trained with straight-through gradients.
- **Two-stage training:** (1) *World model pretraining* with L_WM = λ_pred·L_pred + λ_dyn·L_dyn + λ_rep·L_rep, where L_pred is a cosine loss in embedding space (predicting the successor observation embedding rather than raw observations) and L_dyn / L_rep are opposite-stop-gradient KL terms with a free-bits threshold κ. (2) *Risk-supervised training*: BCE on the immediate-hazard logit against y^haz, and BCE on the prefix-risk logit against a decayed soft target y^pre = exp(−(t^haz − t − 1)/ρ) for precursor steps within horizon K. Only the modules on the computational path to the two risk predictors are unfrozen; the GRU core stays fixed. This partial unfreezing turns the latent dynamics from generically next-state-predictive into risk-aware.
- **Multi-horizon risk estimation:** prefix-risk scores are smoothed by an exponential moving average p^ema (retains persistent weak evidence) and a recent-window mean p^win (retains transient increases), forming the temporal evidence state B_t. A bounded noisy-or fuses them with the immediate-hazard score: S_t = NoisyOr(p^haz, p^ema, p^win).
- **Split-conformal calibrated intervention:** BLOCK if p^haz ≥ λ_block; else HOLD if S_t ≥ λ_hold; else PASS. Thresholds are set on a held-out safe calibration split from trajectory-level maximum scores M_i = max_t S_{i,t}, with λ_hold = M_(k), k = min(⌈(n+1)(1−α)⌉, n), so the false-alert budget is controlled at the trajectory level; λ_block is built the same way from maximum immediate-hazard scores with a stricter budget. Thresholds are frozen after calibration.
- **Implementation:** frozen Qwen3-4B-Instruct-2507 layer-31 pooled features (2560-d) as encoder; deterministic latent 1024, stochastic 32×32; prefix-risk horizon K = 3, decay temperature ρ = 1.5; stage-1/stage-2 epochs 10/12, batch size 8, lr 2×10⁻⁴, KL weight 0.03, free bits 0.2, single H100.

## Experiments & Key Numbers
- **Benchmarks and protocol:** SafetyDrift (long-horizon risk accumulation), AgentDojo, Agent Security Bench (ASB), and ASSE-Security (predominantly immediate hazards). DreamGuard is trained and calibrated **only on SafetyDrift** and transfers the same thresholds zero-shot to the other three. All four are converted to a common step-level format; first hazard steps come from LLM prelabeling plus independent review by two human annotators.
- **Baselines:** generic (Llama-Guard-4-12B); reactive (PolicyGuard, GuardAgent, AgentDoG-1.5); proactive (SafePred, TRACES).
- **Main results (F1 / SR / FPR in %, Latency in s per call):** SafetyDrift 96.4 / 96.3 / 3.7 / 0.027; AgentDojo 74.9 / 76.9 / 29.4 / 0.034; ASB 82.1 / 74.2 / 13.6 / 0.023; ASSE-Security 82.9 / 77.2 / 9.8 / 0.016. Lowest latency on all four benchmarks; average end-to-end 0.025 s (25 ms) per call.
- **Cross-risk robustness:** TRACES reaches 87.1 F1 on SafetyDrift but drops to 27.3 on ASB; PolicyGuard reaches 79.1 F1 on ASSE-Security but only 26.4 on SafetyDrift. DreamGuard avoids this sharp trade-off.
- **Efficiency:** 3.3× faster than TRACES, 3.6× faster than PolicyGuard, 250.6× faster than GuardAgent, 424.0× faster than SafePred.
- **Step-level timing (PHIR / MAS):** SafetyDrift 96.3 / 3.63 (both best), AgentDojo 16.8 / 0.33, ASB 17.3 / 0.27 (both best), ASSE-Security 34.8 / 0.61.
- **Online guardrail:** GPT-5.1 as the function-calling task agent, ASSE-Security online subset of 100 cases (48 unsafe / 52 benign), max 6 online steps, α = 0.6. DreamGuard attains a 72.92% Safety Rate while preserving a 90.38% Utility Rate, placing it beyond the safety–utility frontier formed by existing guardrails.
- **Ablations (ASSE-Security; Full = F1 82.9 / SR 77.2 / FPR 9.8 / PHIR 34.8 / MAS 0.61):** w/o recurrent WM → F1 74.7, FPR 73.7 (SR 100.0 by over-intervening); w/o successor prediction → F1 76.3, FPR 25.4; w/o hazard predictor → F1 52.1, PHIR 13.0 (largest drop); w/o prefix-risk predictor → F1 80.9 but FPR 24.9, PHIR 25.8; w/o temporal aggregation → F1 77.8, SR 70.1; w/o WM pretraining → FPR rises to 92.0; w/o risk-supervised training → FPR only 2.4 but SR 64.1, PHIR 9.8, MAS 0.18 (too conservative).
- **Stated limitations:** thresholds are calibrated exclusively on SafetyDrift, so performance under substantial distribution shift may need lightweight recalibration on target-domain data; the framework decides only *whether* to intervene and does not generate safe replacement actions, leaving task disruption after an intervention unaddressed.
