## 核心问题

更深的网络应该表现更好，但实验表明深度超过一定层数后性能反而下降（**退化问题，degradation problem**）——这不是过拟合，而是训练误差也在增加。如何解决？

## 主要贡献

### 1. 残差连接（Residual Connection / Skip Connection）
核心思想极其简洁优雅：

```
        ┌───────────────────┐
        │                   │ (恒等映射/identity)
输入 x ─┤                   ├─→ (+) ──→ ReLU ──→ 输出
        │  Conv → BN → ReLU │   ↑
        │  Conv → BN ───────┘   │
        │   F(x) (残差)          │
        └───────────────────────┘

输出 = F(x) + x    而不是    输出 = F(x)
```

- 网络只需学习**残差 F(x) = H(x) - x**
- 如果恒等映射就是最优的，网络只需让 F(x) = 0
- 这比学习完整映射 H(x) 容易得多

### 2. 极深网络成为可能
| 模型 | 层数 | ILSVRC Top-5 错误率 |
|------|------|---------------------|
| AlexNet | 8 | 16.4% |
| VGG | 19 | 7.3% |
| GoogLeNet | 22 | 6.7% |
| **ResNet** | **152** | **3.57%** |

论文甚至测试了**1202层**的ResNet，证明训练不会崩溃。

### 3. 超越人类
ResNet在ImageNet上的3.57% Top-5错误率首次**超过了人类水平**（约5.1%）。

## 为什么残差连接有效？

### 梯度流动视角
- 残差连接提供了**梯度高速公路**
- 梯度可以直接从深层回传到浅层，不会消失
- `∂L/∂x = ∂L/∂H × (1 + ∂F/∂x)`，其中 +1 保证了梯度不会消失

### 集成学习视角
- ResNet可以被看作许多**不同深度路径的集成**
- 残差连接使网络具有指数级数量的隐式路径

- Transformer中的残差连接直接来自ResNet
- DenseNet：更密集的跳跃连接
- ResNeXt：分组卷积 + 残差
- 几乎所有现代架构（GPT、BERT、ViT、U-Net等）都使用残差连接
