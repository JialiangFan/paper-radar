# Foundations of Reasoning with Uncertainty via Real-Valued Logics

## Research Problem
How to provide a sound and finitely strongly complete axiomatization for reasoning over a broad class of real-valued logics, including fuzzy, probabilistic, and weighted variants.

## Topic
Real-valued logic axiomatization completeness

## Background
Real-valued logics, where truth values range over the continuous interval [0, 1] rather than the discrete set {0, 1}, have a long history dating back to Boole's probabilistic logic in the 19th century. They have found applications in expert systems, linguistics, hardware design, and databases. With the recent rise of neuro-symbolic AI, where neural network activation values naturally correspond to continuous truth values, there is renewed urgency to establish rigorous formal foundations -- particularly soundness and completeness results -- for reasoning in these logics. Prior axiomatization efforts have targeted individual logics (e.g., Lukasiewicz, Godel) with logic-specific axiom systems, and have dealt only with formulas and their truth values, not with the possible combinations of truth values across collections of formulas.

## Limitations & Research Problem
- **Limitation:** Existing axiomatizations of real-valued logics are fragmented: each logic (Lukasiewicz, Godel, product logic, etc.) requires its own separate axiom system with fixed truth-evaluation functions for each connective. Moreover, these axiomatizations can only infer whether a formula necessarily has truth value 1, but cannot determine the full set of possible truth values a formula may take, nor reason about joint constraints on truth values of multiple formulas simultaneously. Soundness and completeness for many real-valued logics remain uncharacterized, leaving their inference capabilities described only qualitatively.
- **Problem:** How can one construct a single, parameterized axiom system that is simultaneously sound and finitely-strongly complete for a broad class of real-valued logics -- encompassing all common fuzzy logics, weighted variants, and probabilistic interpretations -- while enabling precise inference about all possible combinations of truth values across collections of formulas?

## Contributions
- Introduction of **multidimensional sentences (MD-sentences)**, a rich class of sentences of the form (sigma_1, ..., sigma_k; S), where S is an arbitrary subset of [0,1]^k. These sentences express not only which truth values individual formulas may take, but also how truth values of different formulas interact and constrain one another.
- A unified axiom system consisting of **a single axiom and seven inference rules**, proven to be **sound and finitely-strongly complete** for MD-sentences (Theorem 3.4). This means: whenever a finite set of premises logically entails an MD-sentence, there exists a formal proof from those premises using the axiomatization.
- A robustness result showing that the class of MD-sentences is **closed under Boolean combinations**: any finite Boolean combination of MD-sentences is logically equivalent to a single MD-sentence (Theorem 4.2).
- A **decision procedure called SoCRAtic** (Sound and Complete Real-valued Axiomatic solver) for Lukasiewicz and Godel logic, based on linear programming. Under the assumption that the parameter M (nesting depth) is fixed, the algorithm runs in time polynomial in the number of premises P and the interval bound N (Theorem 6.1). The satisfiability problem is shown to be NP-hard in general.
- Extension of the axiom system to handle **weighted subformulas** (Theorems 7.1, 7.2), where connective evaluation functions take weights as additional arguments, preserving soundness and completeness.
- Extension to the **probabilistic interpretation** of truth values (Theorems 8.1, 8.2), incorporating Venn diagram structure with nonnegativity and normalization constraints while maintaining soundness and completeness.
- Experimental validation of SoCRAtic on k-SAT instances, Hajek's tautologies (82 axioms and tautologies verified in 2.911 seconds), and stress tests with thousands of intervals, demonstrating practical efficiency.

## Methodology
- **Two-layer logical architecture:** The inner layer is a real-valued logic where formulas take truth values in [0, 1], with connectives including conjunction (&), disjunction (the Lukasiewicz or Godel disjunction), implication (->), and negation. The outer layer is classical two-valued logic, where MD-sentences evaluate to True or False using standard Boolean connectives.
- **Formalization via MD-sentences:** A sentence (sigma_1, ..., sigma_k; S) asserts that if the truth value of each sigma_i is s_i, then the tuple (s_1, ..., s_k) belongs to the information set S, which can be any subset of [0,1]^k. This enables expressing arbitrary joint constraints on formula truth values.
- **Axiom and inference rule system:** One axiom (sigma; [0,1]) plus seven rules: (1) permutation, (2) extension with trivial information, (3) intersection of information sets, (4) projection onto subsets of components, (5) restriction to subsets of information, and (6-7) the critical Rule 7, which depends on the specific real-valued logic via the "good tuple" concept. Rule 7 encodes the semantic behavior of each connective into the proof system.
- **Completeness proof strategy:** The proof introduces the notion of minimized sentences, leverages closure under subformulas, and uses Rule 7 to iteratively reduce complex sentences to simpler forms, ultimately grounding them via Axiom 1. A key lemma (Lemma 3.1) establishes that Rule 7 conclusions over closed formula sets are minimized.
- **SoCRAtic decision procedure:** MD-sentences are restricted to interval-based form (each component of S is a finite union of rational intervals). The decision problem is decomposed into feasibility subproblems for systems of linear inequalities derived from connective definitions. Implementation uses mixed-integer linear programming (MILP) with Boolean variable splitting and the IBM CPLEX optimizer.
- **Extensions to weights and probabilities:** For weights, the good-tuple definition is modified so connective evaluation functions accept four arguments (two truth values and two weights). For probabilities, a Venn diagram structure over n atomic propositions is introduced, adding constraints that Venn member values are nonnegative and sum to 1, with truth values of disjoint-union formulas equal to the sum of their constituent Venn members.
