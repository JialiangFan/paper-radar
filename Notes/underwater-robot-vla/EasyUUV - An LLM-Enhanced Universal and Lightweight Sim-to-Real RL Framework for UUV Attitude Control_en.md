# EasyUUV: An LLM-Enhanced Universal and Lightweight Sim-to-Real Reinforcement Learning Framework for UUV Attitude Control

## Topic
LLM-enhanced hybrid control framework combining reinforcement learning, adaptive control, and multimodal LLM runtime parameter tuning for zero-shot sim-to-real UUV attitude control.

## Background
Unmanned underwater vehicles (UUVs) face significant challenges in attitude control due to complex, time-varying hydrodynamics, environmental disturbances (currents, waves), and the difficulty of transferring simulation-trained policies to real-world deployment. Traditional control methods (PID, model-based controllers) require manual tuning and struggle to adapt to unforeseen conditions, while pure RL approaches suffer from the sim-to-real gap. Recent advances in large language models offer new possibilities for adaptive, training-free runtime adjustment of control systems.

## Limitations & Research Problem
- **Limitation:** Pure RL policies trained in simulation face a significant sim-to-real gap for underwater vehicles due to inaccurate hydrodynamic modeling, and traditional controllers require expert manual tuning that cannot adapt to unforeseen runtime conditions. No existing framework combines RL with LLM-driven adaptive control for underwater vehicles.
- **Problem:** How to achieve robust zero-shot sim-to-real transfer for UUV attitude control that can autonomously adapt to unforeseen environmental disturbances at runtime without retraining, while remaining deployable on low-cost hardware.

## Contributions
- A three-tier hybrid control architecture combining RL policy (high-level attitude corrections), Adaptive S-Surface controller (low-level execution), and multimodal LLM agent (runtime parameter tuning) -- the first framework integrating LLMs into underwater vehicle control
- Parallelized RL training pipeline using PPO in Isaac Lab + MuJoCo, completing 3x10^7 training steps in approximately 130 seconds on a single RTX 4060
- LLM-based training-free adaptation mechanism that processes visual logs and textual sensor data to adjust controller parameters (zeta_1, zeta_2) via fuzzy-rule-constrained scaling factors, achieving 78% MSE reduction under turbulent conditions with only 2 adjustment rounds
- A low-cost (~$1000), fully-actuated 6-DOF UUV hardware platform (30L enclosure, <20kg, 8 custom thrusters, ESP32 controller at 100Hz)
- Zero-shot sim-to-real transfer validated through tank experiments and open-sea trials, demonstrating near-zero steady-state error under wave-induced turbulence

## Methodology
- **Hybrid Control Architecture**: Three tiers -- (1) RL policy receives 9D state (current/desired attitude quaternions + depth error), outputs 4D corrections (roll, pitch, yaw, depth), (2) Adaptive S-Surface (A-S-Surface) controller converts corrections to thruster commands using sigmoid-based control law with adaptive compensation term, (3) multimodal LLM tunes controller gains at runtime. The A-S-Surface control equation: u_t = 2/(1+exp(-zeta_1*e(t) - zeta_2*e_dot(t))) - 1 + Delta_u(t), where the adaptive term updates as Delta_u(t+1) = Delta_u(t) + alpha*e(t)*sign(u_t).
- **RL Training**: PPO via RSL-RL library in NVIDIA Isaac Lab with MuJoCo physics. Reward function: orientation alignment r_q = exp(-|q*q_des*|), action penalty r_p = exp(-||a||^b) with b=1, depth tracking r_z = exp(-||Delta_z||^2). Domain randomization: COB-COM offset (0.075-0.15m uniform sphere), volume (1.5-3L uniform), controller gain (15-30% variation).
- **LLM Runtime Tuning**: Multimodal LLM agent observes visual attitude tracking plots and textual sensor summaries. Instead of directly outputting parameter values, the LLM generates constrained scaling factors: 2x/0.5x for major adjustments, 1.5x/0.67x for refinements, applied to controller parameters zeta_1 and zeta_2. This fuzzy-rule constraint prevents catastrophic parameter changes from non-deterministic LLM outputs.
- **Hydrodynamic Modeling**: Phenomenological drag and viscous forces using MuJoCo's inertia-box approximation. Blue Robotics T200 thruster (16V) characterized by piecewise quadratic fit: forward regime (29.54a^2+26.10a-2.44), deadband (-0.08 to 0.08), reverse regime with independent coefficients.
- **Hardware Platform**: ~$1000 total cost. 3D-printed ABS hull with aluminum structure, 30L waterproof enclosure, <20kg total weight. Eight custom thrusters in fully-actuated 6-DOF configuration. ESP32-WROOM microcontroller at 100Hz control rate. MPU9250 9-DOF IMU with complementary filtering. RS-485 tether for real-time command/telemetry.
- **Experimental Setup**: Three evaluation stages -- (1) simulation ablation in Isaac Lab comparing RL vs non-RL, A-S-Surface vs S-Surface vs PID, and domain randomization scales, (2) tank experiments validating zero-shot transfer with and without disturbances and LLM tuning, (3) open-sea trials under wave-induced turbulence. Baselines: S-Surface controller, PID, and variants without RL or without LLM tuning.
- **Key Results**: (1) RL reduces compound tracking MSE by 77% (0.452 to 0.103). (2) A-S-Surface outperforms S-Surface and PID consistently. (3) Small-scale DR outperforms large-scale DR for cross-domain generalization (MSE 0.0087 vs 0.0110 under buoyancy shift). (4) Tank: RL reduces yaw+roll MSE from 0.3836 to 0.2356, std from 0.150 to 0.080. (5) LLM tuning under turbulence: 2 adjustments reduce MSE from 0.0812 to 0.0179 rad^2 (78% reduction). (6) Sea trials: near-zero steady-state error under waves, confirming zero-shot transfer.
- **Limitations**: Simulation fidelity constraints (MuJoCo hydrodynamics are phenomenological, not CFD-based), non-deterministic LLM behavior requiring fuzzy-rule constraints, evaluation limited to a specific low-cost platform and attitude-tracking tasks (not tested on navigation or manipulation).
