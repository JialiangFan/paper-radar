# Semantic-Sensitive Underwater Image Enhancement with VLM

## 主题
VLM-guided semantic underwater enhancement

## 背景
水下图像因光照吸收与散射出现严重退化，水下图像增强（UIE）已成为海洋探索、生物监测和水下机器人视觉的重要预处理环节。然而，主流基于深度学习的 UIE 方法以人眼感知质量为目标，与下游机器视觉任务（检测、分割）的需求之间存在明显鸿沟，常常在追求全局视觉提升的同时破坏关键语义线索。

## 现有局限与研究问题
- **Limitation:** 现有 UIE 方法是"任务无关/语义盲"的，全局均匀增强会引入伪影并造成与下游模型数据期望不一致的分布偏移；早期基于语义分割图的引导高度依赖稀缺的像素级标注，而近期基于 VLM 的方法仅采用全局风格化文本提示（如"a clear underwater photo"），无法关注图像中的具体物体内容，难以做到细粒度、目标级的内容感知增强。
- **Problem:** 如何利用 VLM 的开放世界理解能力，让 UIE 网络在重建过程中"知道关注什么"，将修复资源集中在语义关键区域，从而同时提升人眼感知质量和下游检测/分割任务的性能。

## 贡献
- 提出 VLM 驱动的语义敏感学习策略（-SS），针对传统 UIE 的语义盲性，使增强结果同时对人类感知和机器认知都更鲁棒。
- 设计双引导机制：通过交叉注意力注入模块对网络信息流进行结构性引导，并提出新的语义对齐损失对中间特征进行显式正则化。
- 该机制是即插即用的：在 PUIE、SMDR、UIR、PFormer、FDCE 五个 SOTA 编解码 UIE 基线上验证，全面提升 PSNR/SSIM/LPIPS/UIQM/UCIQE 等感知指标，并在 Trash-ICRA19 检测和 SUIM 分割任务上一致性提高 mAP 与 mIoU。

## 方法论
- **语义引导图生成：** 用 LLaVA 对退化图像 Id 生成关键物体的文本描述 T；用 BLIP 的视觉编码器 Φv 与文本编码器 Φt 分别提取 patch 特征 Fv 和全局文本特征 ft。
- **跨模态对齐与锐化：** 通过 cosine 相似度计算每个 patch 与文本的相关性 si；用语义锐化函数 Ψsharp(si; γ, δ) = (max(0, N(si) − δ))^γ 结合阈值过滤与幂律变换，抑制背景噪声、放大高相关区域，再上采样得到单通道空间语义引导图 Msem。
- **交叉注意力注入：** Msem 下采样到与 skip-connection 编码特征 el 相同分辨率得到 M̃(l)，逐元素加权 el 后线性投影生成 K、V，由解码器特征 dl 作为 Q 进行交叉注意力，使解码器优先抽取语义"被点亮"区域的信息。
- **显式语义对齐损失：** L(l)_align = ‖F(l) ⊙ (1 − M̃(l))‖²_F − η⟨F(l), M̃(l)⟩，前一项抑制背景区域不必要的强响应，后一项奖励前景关键区域与语义图一致的强响应。
- **总目标：** Ltotal = Lrecon + λalign · Σ L(l)_align，其中 Lrecon = L1 损失 + VGG-19 感知损失，λalign 经验设为 0.1。
- **消融发现：** BLIP 的融合式对齐生成的引导图比 ViT class-attention 与 CLIP 更干净精确；将语义引导仅注入解码器优于编码器或全部阶段注入，因其直接调控图像重建过程。
