# AI-Powered Autonomous Underwater System for Sea Exploration

## Topic
AI-integrated AUV detection pipeline

## Background
Traditional sea exploration is hampered by extreme pressure, poor visibility, and unpredictable underwater terrain; human divers are limited to roughly 50-minute dives and the resulting data takes weeks to analyze, leaving about 95% of the ocean unexplored despite covering 70% of Earth's surface. Recent progress in computer vision, machine learning, and large language models opens the door to safer, faster, and more insightful exploration via Autonomous Underwater Vehicles (AUVs). This paper proposes an end-to-end AI pipeline that fuses YOLOv12 Nano detection, ResNet50 feature extraction, PCA dimensionality reduction, K-Means++ clustering, and GPT-4o Mini LLM reporting into a single AUV system.

## Existing Limitations and Research Question
- **Limitation:** Prior underwater AI works (DeepFins, MERLION, MarineInst, MarineGPT) each tackle only one stage of the workflow — detection, segmentation, or vision–language captioning — and none integrates YOLO detection, CNN/PCA feature processing, K-Means clustering, and LLM-based natural-language reporting into a unified automated pipeline; meanwhile generic LLMs lack marine-specific knowledge and the available training data suffer from class imbalance and quality degradation.
- **Problem:** How can we build an end-to-end, hardware-feasible AI pipeline for an AUV that performs real-time underwater object detection, groups detections via feature-level clustering to reveal latent or unknown categories, and automatically produces structured scientific reports — thereby reducing the risks of human diving and accelerating marine data interpretation?

## Contributions
- Proposes the first integrated underwater AI system that chains YOLOv12 Nano detection, ResNet50 feature extraction, PCA reduction, K-Means++ clustering, and GPT-4o Mini reporting into a single automated pipeline running from raw video frames to natural-language scientific summaries.
- Trains and evaluates the system on a merged DeepFish + OzFish dataset of 55,722 Australian marine images covering 496+ fish species and 60k+ instances, achieving mAP@0.5 = 0.512, Precision = 0.535, Recall = 0.438, with consistent inference speed of 2.0–5.5 ms per frame.
- Demonstrates that PCA can compress CNN features to 150–900 components while preserving 98% cumulative variance, enabling K-Means++ to discover 27 meaningful clusters from 687 detection crops and revealing latent patterns of fish shape, lighting, and pose that hint at potential new species.
- Designs marine-specific LLM prompts that combine detection crops, clustering HTML, and GPS coordinates as multimodal context for GPT-4o Mini, automatically generating structured detection/cluster summaries describing shape, texture, habitat, and geographic location, with Plotly + Dash map visualization prototyped for the Arabian Gulf.
- Provides a systematic literature gap analysis across YOLO, CNN, K-Means, and LLM lines of research, identifies the absence of end-to-end integration as the core gap, and outlines five future directions: addressing class imbalance, taming the curse of dimensionality, training local marine-LLMs, expanding to seahorses/shrimp/crabs/plants, and model quantization for real-world deployment.

## Methodology
- **System architecture (seven modules):** Autonomous Vehicle (cameras, LiDAR, GPS sensors) → YOLO Object Detection Module → GPS Localization Module → Mapping Module → Image Preprocessing Module (CNN feature extraction) → K-Means Clustering Module (PCA + Kmeans++) → Large Language Model API Module (OpenAI GPT-4o Mini); each module runs independently and caches outputs into a unified Data Repository for downstream consumption.
- **Detection stage:** YOLOv12 Nano with attention-centric design (Ultralytics) is trained for 170+ hours on a Ryzen 9 5900X + RTX 3070 Ti + 32 GB RAM workstation; DeepFish (4,505 frames) and OzFish (51,217 frames) are merged at 1920×1080, split 85/15 train/val, and inference outputs bounding boxes filtered by confidence thresholds.
- **Feature & dimensionality stage:** ResNet50 extracts deep feature vectors from each detection crop and flattens them; PCA is applied twice — once to refine features for clustering and once for 2D/3D visualization — with the number of components adapting to crop count (150–900) targeting 0.98 cumulative explained variance, with hardware-driven adjustments when crop count exceeds 2,000.
- **Clustering stage:** K-Means++ initialization speeds up convergence and improves cluster quality; the system clusters 687 detection crops into 27 groups, visualizes them in the PCA-reduced feature space via Plotly, and validates assignment by manually picking 4 crops with varied lighting/angle/shape and checking their cluster membership for similarity and novel-class discovery potential.
- **LLM reporting stage:** GPT-4o Mini is invoked through the OpenAI API with task-specific prompts for "Detection" and "Cluster Analysis"; image crops or cluster HTML are attached and GPS coordinates injected, producing structured summaries covering shape, size, texture, discernible patterns, habitat, and common locations; Plotly + Dash simulate single- and multi-detection visualization on an Arabian Gulf map for real-world deployment scenarios.
- **Evaluation metrics:** YOLO is measured with mAP@0.5, Precision, Recall; PCA with retained components and cumulative explained variance; K-Means with cluster count k; additionally, four hand-picked YouTube underwater videos provide external inference validation across confidence thresholds from 0.85 down to 0.1 to probe robustness.
