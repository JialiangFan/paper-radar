# AquaticCLIP: A Vision-Language Foundation Model for Underwater Scene Analysis

## Topic
Domain-specific vision-language foundation model for underwater scene understanding, leveraging large-scale aquatic data and novel dual-encoder architecture for zero-shot underwater perception tasks.

## Background
Large-scale vision-language models like CLIP have demonstrated remarkable generalization capabilities across diverse visual domains. However, their performance in specialized underwater environments is limited due to the scarcity of domain-specific aquatic image-text training data. Underwater imagery presents unique challenges including color distortion, low contrast, turbidity, and domain-specific organisms and structures that general-purpose VLMs struggle to interpret. AquaticCLIP addresses this gap by constructing a 2-million aquatic image-text pair dataset and designing a contrastive learning framework tailored for underwater scene analysis, published in IEEE Transactions on Neural Networks and Learning Systems (TNNLS).

## Limitations & Research Problem
- **Limitation:** General-purpose VLMs (CLIP, BLIP-2, GPT-4V) perform suboptimally on underwater visual tasks due to the absence of large-scale, domain-specific aquatic image-text training data. Existing underwater datasets are small-scale and task-specific, preventing the development of unified aquatic foundation models.
- **Problem:** How to build a vision-language foundation model that achieves strong zero-shot generalization across diverse underwater scene analysis tasks (classification, detection, segmentation, counting) by effectively aligning aquatic visual and textual representations?

## Contributions
1. Construction of the first large-scale aquatic image-text dataset comprising 2 million pairs from heterogeneous sources (YouTube, Netflix, National Geographic, 1200 marine biology textbooks, scientific journals, Corals of the World, Fishes of Australia, Marine Twitter), with automated description generation and semantic filtering
2. A novel Prompt-Guided Vision Encoder (PGVE) that uses learnable prompts via cross-attention to progressively aggregate image patch features, prioritizing semantically relevant regions while suppressing irrelevant background
3. A Vision-Guided Text Encoder (VGTE) that enriches textual representations with visual context through cross-modal attention, improving vision-language alignment for underwater-specific terminology
4. An unsupervised description generation pipeline using MarineGPT (image-level) and MRegionCLIP (instance-level) with cosine similarity-based semantic filtering to produce high-quality training text
5. State-of-the-art zero-shot performance across underwater species classification, fine-grained fish identification, coral classification, object detection, and counting, substantially outperforming GPT-4V, BLIP-2, and fine-tuned CLIP variants

## Methodology
- **Dataset Construction (2M pairs)**: Sources include YouTube documentaries (unique frames extracted every 50 seconds using keywords like "underwater world", "marine documentary"), Netflix documentaries ("My Octopus Teacher", "Wonders of the Reef"), National Geographic, 1200 marine biology/oceanography textbooks (figures extracted via PDF-Figures 2.0), Corals of the World and Fishes of Australia repositories, and Marine Twitter (channels with 100+ followers). Manual curation yields 2M high-quality image-text pairs. Unsupervised descriptions generated by MarineGPT (image-level) and MRegionCLIP detector (instance-level), semantically cleaned by retaining top-p% keywords based on cosine similarity with image embeddings.
- **Prompt-Guided Vision Encoder (PGVE)**: Input images divided into non-overlapping patches processed by frozen ViT-B/16-224 to produce patch embeddings. A set of learnable prompt features (20 prompts) guide progressive feature fusion via cross-attention: prompts serve as queries, patch features as keys/values, with learnable weight matrices (W1, W2, W3, W4). This prioritizes patches with high semantic similarity to learned task-relevant prompts.
- **Vision-Guided Text Encoder (VGTE)**: Text representations from CLIP's text encoder are refined through vision-guided attention. Patch features and learned prompts are concatenated to serve as keys/values, while textual representations serve as queries. This injects visual context into text representations for improved cross-modal alignment.
- **Training Objective**: Symmetric contrastive loss combining image-to-text loss and text-to-image loss. Fine-tuned components: image encoder, text encoder, PGVE, and VGTE (MarineGPT caption generator remains frozen).
- **Experimental Setup**: Trained on 4x A100 GPUs for 80 epochs; Adam optimizer with lr=1e-4, weight decay=1e-5; batch size 512; 20 learnable prompts. Evaluated across zero-shot marine species classification (MAI, SAI), fine-grained fish classification (FishNet, FNOI, LSF), coral classification (CSC, CC), object detection (FishNet, DeepFish, Brackish, URPC), and linear probe settings. Baselines include Frozen CLIP, Fine-tuned CLIP, CoOp, MAPLE, GPT-4V, BLIP-2, MarineGPT, ResNet-101, ViT-L, ConvNeXt.
- **Key Results**: Zero-shot classification -- CC 95.3% F1 (vs. GPT-4V 87.6%, BLIP-2 85.3%, Fine-tuned CLIP 83.1%); CSC 96.4%; LSF 93.4%; SAI 92.3%; MAI 87.1%. Detection (mAP50) -- FishNet 90.3% (vs. MarineInst 85.4%, MRegionCLIP 86.7%); DeepFish 89.1%; Brackish 87.7%; URPC 83.7%. Linear probe -- SAI 94.4%; FishNet 92.3%; LSF 96.1% (vs. ResNet-101 74.0%, ViT-L 83.3% on SAI). Demonstrates that domain-specific pre-training on large-scale aquatic data yields substantial gains over general-purpose VLMs across all underwater perception tasks.
