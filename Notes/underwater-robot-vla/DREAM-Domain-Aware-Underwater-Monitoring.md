# DREAM - Domain-aware Reasoning for Underwater Monitoring

## 主题
VLM-guided underwater monitoring autonomy

## 背景
海洋暖化与酸化导致温度敏感贝类（如牡蛎）大规模死亡风险升高，对长期、广域、低成本的水下生境监测提出迫切需求；而潜水员作业昂贵且危险，使机器人方案成为更安全高效的替代。然而现有 ROV 系统通常依赖人工操作或纯模仿学习方法，缺乏在未知海域中实时感知环境、动态调整策略的"智能大脑"。本文提出 DREAM，一个由视觉-语言模型（VLM）驱动的自主水下勘探与栖息地监测框架，将海洋领域知识注入推理过程以实现持久化、低成本的底栖监测。

## 现有局限与研究问题
- **Limitation:** 现有水下监测方法多为基于模仿学习的特定领域系统，缺乏来自外部世界的反馈闭环；OceanPlan、OceanChat、AquaChat++ 等 LLM/VLM 系统能进行自然语言导航或多 ROV 协调，但缺少结构化空间记忆、稳健的领域推理和高效再规划能力，且依赖目标先验位置。
- **Problem:** 如何在没有目标先验位置的情况下，让水下机器人结合海洋领域知识与持久化空间记忆，对感兴趣对象（如牡蛎、沉船）执行高效、广覆盖、长时段的自主探索与监测。

## 贡献
- 提出感知 / 认知感知规划 / 控制三层架构，端到端地从原始多模态感知打通到高层 VLM 推理与底层 PD 自适应控制。
- 构建 VLM 驱动的框架，通过 Chain-of-Thought 推理将海洋领域知识与序列化决策融合，生成无需对象定位先验的持久化监测策略。
- 在 BlueROV2 平台上的真实水池部署，验证了该框架对牡蛎礁、沉船等多种感兴趣对象的高效自主勘探能力。
- 开源合成环境 (Oystersim)、真实世界数据集和代码，推动水下机器人监测研究。
- 实验结果：牡蛎任务相比 UIVNAV 基线减少 31.5% 时间，相比原始 VLM 减少 23% 步数并多覆盖 8.88% 牡蛎；沉船场景 100% 覆盖且无碰撞，比 vanilla VLM (60.23%) 显著领先。

## 方法论
- **感知模块 (Perception)**：前向相机提供 RGB、深度与语义分割图像；通过相机内外参将像素反投影为 3D 点云，按高度阈值分为目标 (oysters)、障碍、自由空间三类，并通过射线投射 (ray-casting) 在机器人 FOV 内增量更新 2D 占据栅格地图，记录已探索 / 未知 / 占用区域，作为持久化空间记忆。
- **认知感知规划 (Cognitive-Aware Planning)**：以 GPT-5 作为 VLM，输入包括 RGB、分割、深度图像与占据地图。使用精心设计的 Prompt 明确任务（高效全面发现并映射所有牡蛎簇）、定义完成标准（绿色目标区被灰色已探索像素完全包围且无白色缺失）；引入手工 CoT 提示，包含 6 个推理步骤：分布分析 → 选择当前目标区 → 完成检查 → 选择下一前沿 → 安全可行性确认 → 离散动作选择（方向 + 转角 + 步长）。VLM 仅输出高层动作，因推理较慢不直接做底层控制。
- **控制模块 (Control)**：平面 PD 控制器跟踪由 VLM 输出的离散航点，用机体坐标系下的位姿误差驱动速度命令；垂直方向由 ROV 自带深度保持稳定。状态估计采用 Invariant EKF (InEKF) 与 Cascade IPG 观测器，融合 IMU 与 DVL 水相对速度，在剧烈偏航或 DVL 间歇性丢失底锁时仍能给出鲁棒姿态/速度估计；当策略输出 "Stop" 时使用零速度伪测量抑制漂移。
- **整体闭环**：language actions → 短航点段 → PD 跟踪，状态由 IMU+DVL 提供，连续时间对齐时由场景支持。感知 (oyster 分割) 与控制稳定性显式解耦以维护安全性。
- **实验设置**：在 Oystersim 仿真中跨 15 个含障碍环境（10 牡蛎礁 + 5 沉船，环境尺寸 40-50 m）进行评估，最大 200 步；牡蛎度量为覆盖数量百分比，沉船为覆盖面积百分比。基线为 UIVNAV（零样本目标导航）和无 CoT 的原始 VLM。真实部署在 12 ft 直径 × 5 ft 深的水池中，BlueROV2 + IMU + Waterlinked DVL-A50，圆弧排列牡蛎壳与两根管道模拟沉船，验证端到端实时执行。
- **未来工作**：引入 DINOv3 特征提升泛化、训练基于 Mamba 的紧凑本地 VLA 模型、剪枝与极端量化实现板载推理，并扩展至 3D 洞穴探索。
